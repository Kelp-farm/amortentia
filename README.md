# Amortentia: A Hogwarts Love Story

브라우저에서 플레이하는 한국어 비주얼 노벨 선공개판입니다.

게임 실행: https://kelp-farm.github.io/amortentia/

비공식 무료 팬 프로젝트입니다. Harry Potter 세계관과 원작 캐릭터의 권리는 각 권리자에게 있습니다. 《악역영애 말포이》를 참고한 대체 세계선이 포함됩니다. Ren'Py로 제작했으며 음악과 글꼴 크레딧은 게임 배포 파일에 포함되어 있습니다.

선공개판으로 대사와 연출은 계속 개정됩니다. 저장은 현재 브라우저에 보관되며 메뉴에서 내보낼 수 있습니다.
